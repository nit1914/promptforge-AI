## 🌟 Overview

**PromptForge AI** is a production-grade AI Prompt Engineering platform inspired by the design aesthetics of **Apple, Vercel, Linear, OpenAI, Notion, and Claude**. It turns raw, vague prompts into high-converting, battle-tested directives tailored for 10+ state-of-the-art AI models including ChatGPT (GPT-4o), Claude 3.5 Sonnet, Gemini 1.5 Pro, DeepSeek R1, Grok 2, and Midjourney v6.

---

## 🔥 Key Features

### 1. 🎯 13-Metric AI Quality Analyzer & Judge
- **Circular SVG Score Gauge (0-100%)**: Instant overall quality index calculation with tier badges (*S-Tier Expert, A-Tier Strong, B-Tier Moderate*).
- **13 Diagnostic Score Metrics**:
  - `Clarity`, `Specificity`, `Context`, `Goal Definition`, `Constraints`, `Audience`, `Output Format`, `Reasoning Quality`, `Creativity`, `Prompt Engineering Score`, `Hallucination Risk` *(lower is better)*, `Ambiguity Score` *(lower is better)*, and `Completeness`.
- **AI Judge Diagnosis**: Detailed breakdown of Strengths, Weaknesses, Missing Context, Missing Constraints, Missing Audience, Missing Format, and Actionable Suggested Refinements.

### 2. 🪄 3 Refactored AI Prompt Versions
- **Better Version**: Cleaned structure with baseline action verbs.
- **Professional Version**: Executive consulting format with clear scope boundaries.
- **Expert Version (⭐ CoT)**: Systematic Chain-of-Thought protocol, Few-Shot exemplars, and strict output schema directives.

### 3. ⚖️ Side-by-Side Prompt Comparator
- Compare Original vs. Improved prompt directives in real-time.
- Calculate **Quality Gain Diff %**, **Token Efficiency %**, **Readability Index**, and **Estimated LLM Success Rate**.

### 4. 🔮 Universal Prompt Generator Studio (40+ Use Cases)
- Build tailored prompts across 40+ domain categories:
  - *Image Generation, UI/UX Design, Logo Design, Dashboard, Landing Page, Mobile App, Figma Wireframe, Coding, Python, SQL, Power BI DAX, Excel Formulas, Deep Research, Notes, Resume Builder, LinkedIn Generator, YouTube, SEO, Social Media, Business Pitch Decks, etc.*
- **Advanced Options**:
  - *Prompt Type*: Open Ended, Close Ended, Scenario, Opinion, Multi-Part.
  - *Prompt Technique*: Role Playing (Persona), Meta Prompting, World Building, Deep Research, Gap Finder, Confidence Scoring, Chain-of-Thought, If-Then Logic.
  - *Output Style*: Markdown, JSON Schema, Structured Table, Executable Code, Step-by-Step Checklist, Executive Briefing.

### 5. 🎨 Specialized AI Creative Studios
- **Image Prompt Studio**: Custom camera lens specs (35mm, 85mm f/1.4), volumetric lighting, aspect ratios (`--ar 16:9`, `9:16`, `1:1`), stylize parameters for Midjourney v6, Flux.1 Pro, Imagen 3, and DALL-E 3.
- **Video Prompt Studio**: Camera motion directives (*FPV Drone Flythrough, Smooth Zoom-In, Pan, Orbit 360, Tracking Shot*), motion strength (1-10), and target duration for Runway Gen-3, Veo 2, OpenAI Sora, Luma, and Kling AI.
- **UI/UX & Figma Studio**: Glassmorphic design tokens, color palette directives, and component specs for SaaS, Dashboards, CRM, ERP, and Mobile Apps.

### 6. 📚 Academic Notes Creator & Deep Research AI
- Transform raw text into **Lecture Notes, Exam Prep Flashcards, Mind Map outlines, and Handwritten-style study guides**.
- Deep Research engine supporting academic citation styles (**IEEE, APA 7th, Harvard, Executive Briefing**).

### 7. 📤 Multi-Format Export Engine
- Export prompt guides and diagnostic reports instantly in:
  - 📄 **PDF (.pdf)** *(Powered by jsPDF)*
  - 📝 **Word (.doc)**
  - 📋 **Markdown (.md)**
  - 📄 **Plain Text (.txt)**
  - ⚙️ **JSON (.json)**

### 8. 🏆 Gamification & Daily Streak
- Live **7-day streak counter (`🔥 7 Days`)** with celebratory confetti triggers.
- Unlockable engineering badges (*Prompt Artisan, Streak Master, Prompt Perfectionist, Polyglot Architect*).
- Global PromptForge Leaderboard.

## 🚀 Quick Start & Installation

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### Installation Steps

1. **Clone the Repository**
   ```bash
   git clone https://github.com/nit1914/promptforge-AI.git
   cd promptforge-AI
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run Development Server**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173/`

4. **Build for Production**
   ```bash
   npm run build
   ```
